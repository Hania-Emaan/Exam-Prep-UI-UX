# TutorMigo — AI-Powered Exam Preparation Platform

An interactive, responsive single-page web application designed to help students prepare for high-stakes exams through structured study pathways, practice drills, timed test simulations, and visual progress tracking.

## 🌟 Key Features

* **Multi-Exam Tracks:** Seamless switching between specialized exam paths (e.g., IELTS Academic and IELTS General Training).
* **Interactive Test Simulator:** Full exam section drills (Listening, Reading, Writing, Speaking) with timing and question tracking.
* **Mistake Notebook:** Local review system that captures missed questions and allows step-by-step re-testing.
* **Personalized Dashboard:** Centralized view for study schedules, streak tracking, target score monitoring, and gap analysis.
* **Study Material Uploads:** Upload and organize custom notes, PDFs, and past papers into local session storage.
* **Responsive Teal Design:** Clean, accessible user interface optimized for desktop, tablet, and mobile browsers.

---

## 🛠️ Technology Stack

* **Frontend:** HTML5, Modern CSS3 (CSS Grid, Flexbox, Custom Properties), Vanilla JavaScript (ES6+).
* **Architecture:** Component-driven Single Page Application (SPA) architecture without external runtime dependencies.
* **State Management:** Browser `localStorage` for offline session persistence.
